# Bake Catch — Separate PNG Assets v1

ชุดภาพแยกไฟล์ 21 PNG สำหรับใช้ประกอบเกมหรือเอกสารออกแบบ

## เนื้อหา

- ingredients/01–11: สตรอว์เบอร์รี นม ไข่ ชีส มะเขือเทศ แป้ง ขนมปัง เนื้อ ช็อกโกแลต ดาวโบนัส และระเบิด
- recipes/12–14: เค้กสตรอว์เบอร์รี พิซซ่า และเบอร์เกอร์
- ui/15–16: นาฬิกาจับเวลาและหมวกเชฟ
- branding/17_bake_catch_logo.png: โลโก้ Bake Catch แบบวาดแยกใหม่
- ui/18_heart.png: หัวใจ
- ui/19_pause_button.png: ปุ่มพัก
- character/20_main_menu_chef.png: เชฟหน้าเมนูหลักจากเกมจริง
- background/21_bakery_16x9.png: พื้นหลังร้านจากเกมจริง ไม่มีตัวละครหรือ HUD ทับ

## ที่มาของภาพ

ภาพใหม่ 19 ไฟล์สร้างด้วย built-in image_gen โดยอ้างอิง artwork ของ Bake Catch
วัตถุดิบ เมนู และไอคอนหลักอ้างอิง:
 unity-game/Assets/Resources/BakeCatch/Ingredients.png

ภาพเหล่านี้เป็นการวาดแยกตามต้นแบบ ไม่ใช่การ crop ที่ตรงกับต้นฉบับทุกพิกเซล
โลโก้วาดใหม่โดยใช้สีและองค์ประกอบเดิมเป็นแนวทาง จึงอาจต่างจากไฟล์ Logo.png ของเกม

เชฟและพื้นหลัง 2 ไฟล์คัดลอกจาก Chef.png และ Bakery.png ของเกมโดยไม่เปลี่ยนพิกเซล
ไฟล์ทั้งหมดเป็นภาพเดี่ยว ไม่มี sprite sheet

## พื้นหลังโปร่งใสและขนาด

ภาพทั้งหมดนอกจากพื้นหลังร้านเป็น RGBA มี alpha โปร่งใสจริง
โลโก้ยังมีเงาเรืองนุ่มโปร่งแสงรอบขอบ จึงไม่ใช่โลโก้ขอบแข็งล้วน
พื้นหลังร้านเป็น RGB แบบเต็มฉาก ไม่โปร่งใส และมีขนาด 1672 × 941 ใกล้เคียง 16:9

วัตถุดิบและภาพส่วนใหญ่มีขนาด 1254 × 1254
ขนาดของแต่ละไฟล์และข้อมูล alpha อยู่ใน ASSET_MANIFEST.json

## การนำไปใช้ใน Unity

ภาพไอคอน/ตัวละคร:
- Texture Type: Sprite (2D and UI)
- Sprite Mode: Single
- Alpha Source: Input Texture Alpha
- Alpha Is Transparency: เปิด
- Filter Mode: Bilinear
- Wrap Mode: Clamp
- ใช้ Preserve Aspect สำหรับ Image บน UI
- อย่าใช้ขนาดภาพต้นฉบับเป็นขนาดแสดงผลโดยตรง ให้ปรับตาม layout เกม

พื้นหลังร้าน:
- รักษาสัดส่วนภาพเมื่อวางเต็มจอ
- วางแยกจากตัวละครและ UI
- ไม่ควรเปิด alpha blending โดยคาดว่าจะเป็นภาพโปร่งใส

ชุดนี้ยังไม่ถูกนำไปแทน artwork ภายใน Unity
ไม่มีการแก้โค้ด ฉาก scoring, sensor หรือ Firebase ในงานชุดภาพนี้

คำสั่งสร้างภาพฉบับเต็มของแต่ละภาพใหม่อยู่ใน GENERATION_PROMPTS.md
